# Flagship Moat Research Skill Methodology
(Local Copy from /Users/divyyadav/developer/another-tool/.agents/skills/flagship-moat-research/SKILL.md)

Summary of Non-Negotiable Rules:
1. Treat statements as fact only when sources support them (Verified, Derived, Inference, Hypothesis).
2. Never invent competitor names, pricing, plan limits, complaints, traffic, search demand, user behavior, technical capability, or outcome metrics.
3. Mark unknown unless tested workflow or first-party evidence establishes absence.
4. Do not mistake "free", "AI", "local", "faster", or "more features" for a moat. Explain user value mechanism and copy resistance.
5. Provide full candidate set and rigorous scorecards.
6. Preserve stated constraints: 100% client-side, zero-backend, zero-upload privacy.
